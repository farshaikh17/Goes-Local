# v17.00-shared — SEO audit fixes (Miami Goes Local Technical SEO Audit, 12 Nov 2026)

Eric (12 Nov): "lets help the SEO team" with their audit (Google Doc "Miami Goes Local — Technical SEO Audit").
Each finding was checked against the live site and the code first.

## Already fine (no change; told the SEO team)
- www → apex is one 301 for every path, including /sitemap.xml (checked with curl).
- Sitemap-index lastmod is each file's real latest change (MAX(updated_at)); the four children matched because a sync
  had just written listings. Listing entries carry their own updated_at.
- HSTS is set on every response by the outer fetch handler.
- lc.miamigoeslocal.com is GoHighLevel's email-sending subdomain (CITY_FROM_EMAIL noreply@lc…), not a website.
- The site does not strip dashes: a title saved through Admin → Blog with "—", ":" and "|" is stored as typed (tested
  locally). The stripped titles arrived that way (copy/paste tool); fixed in the data below.

## Changes (worker)
- robots.txt: every AI-bot group now also has Disallow /admin and /manage; Crawl-delay removed.
- /login: out of sitemap-categories.xml and served with X-Robots-Tag noindex, follow.
- Thin pages: a sub-category page with fewer than THIN_SUB (3) listings gets <meta name="robots" content="noindex,
  follow"> and is left out of the sitemap (still reachable for visitors). New PAGE option `noindex`.
- "— 1 listings" → "— 1 listing" in sub-category titles; the count is formatted.
- Blog structured data: when a post's own JSON-LD (custom_schema) has BlogPosting/Article, the automatic Article is
  dropped, and when it has a BreadcrumbList, the automatic one is dropped — no more doubles (29 of 36 Miami posts).
  The post's BlogPosting gets dateModified from updated_at when it has none (`LDNODES`).
- A byline that is a team ("Miami Editor Team") is typed Organization, not Person (blog and news, `AUTHORLD`).
- /best hub: CollectionPage + ItemList (first 50 lists) + BreadcrumbList.
- Fonts: the Google Fonts @import was removed from the page CSS; every HTML page gets preconnect + a non-blocking
  stylesheet link (+ noscript) in <head> through HTMLRewriter (`FONT_CSS_URL`). Render-blocking request gone.
- Photo-library (images.unsplash.com) addresses in src/style/data-src/content are rewritten to w≤1400, quality 70, no
  forced JPEG (`UNSPLASH_SM`): Miami home page photos 2.8 MB JPEG → 1.3 MB AVIF in a local test.
- Blog/news <title>: " | brand" is added only if the whole title stays within 60 characters (`BRANDTITLE`).
- precheck also bundles worker.js with esbuild (as Wrangler does): node --check missed a duplicate `const` in module
  scope during this release.
