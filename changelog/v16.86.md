# v16.86-shared — every owner verifies email and phone; Facebook ad tracking in GHL; Meta Pixel setting

Eric (2 Nov, meeting notes): "Owner Email and Phone Verification Mandatory … only owner can do those things";
"we send OTP and get details"; "every owner has to verify both emails and phone"; ads on Meta for owners to claim —
"We don't want the specific report to be on the domain but on GHL, so we need to find a way to track those leads";
the Pixel ID "needs to be a variable, so that we are able to add it in all others".

## Changes
- **Owner phone check (texted code).** After the email check (the sign-in code, or the claim's verification code),
  /manage/confirm asks for the email again, the owner's full name, mobile and year established, then texts a 6-digit
  code to that mobile. Only the right code (15 minutes, 5 tries, 4 texts, a minute apart; shares the 300-a-day text
  ceiling) saves Owner Name / Owner Phone / Year established to GHL and counts the listing as claimed. Tags
  `owner-email-verified` + `owner-phone-verified`. "Text it again" and "Change number" on the code page.
  - The text goes through the business contact to the typed number (`toNumber`), so it shows on the business's
    Conversations and no new contact is made; if GHL refuses a number the contact doesn't have, the number is added
    to the contact as an extra phone first (native-fields-only call).
  - Applies to everyone: owners held by a sales Listing Verified, owners whose website claim was approved, and owners
    from before today (new table `owner_verified`). Until done, /account and every /manage page send them to the check.
    Team members (Team tab) are not asked — only the owner.
  - An approved claim now also records the Owner Email in D1 straight away, so the check applies at once.
- **Facebook / Instagram ad leads tracked in GHL (no report on the site).** A visitor from an ad (utm_source facebook /
  instagram / fb / ig / meta, or Meta's `fbclid` on the link) gets, on their business contact, the tag `facebook-ad`
  plus a tag per step: `fb-claim-form`, `fb-sign-up`, `fb-add-a-business`, `fb-quote-request`, `fb-advertise-form`,
  `fb-owner-verified`, and a note with the campaign and first page. GHL smart lists / reports count each step.
  `fbclid` alone now counts as Facebook (paid) in the first-touch cookie, so Lead Source reads "… (Facebook ads)".
- **Meta Pixel per city: `CITY_META_PIXEL`** (Cloudflare → worker → Settings → Variables, digits only). When set:
  PageView on every page, Lead when a claim / add-a-business / sign-up form is sent, CompleteRegistration when an
  owner finishes the email + phone check. Not set = no pixel.
