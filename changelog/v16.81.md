# v16.81-shared — sign-up flood protection (Tampa bot attack, 27–28 Oct)

Eric (28 Oct): "What the Hell happened in Tampa, is that a bot attack? We got charged for thousands of emails."

## What happened
- 27 Oct 22:45 → 28 Oct 05:43 UTC, Tampa only. About 149,000 POSTs to /api/signup, almost all from Tor (Cloudflare
  country "T1"), each with a different fake browser and a real person's email address (an "email-bombing" attack using
  our sign-up form to send people unwanted mail).
- Each one made the site send the "confirm your email" code through GHL: **81,468 emails queued** in Tampa's GHL
  (Cloudflare logs, "ghl email queued"), each billed by GHL. Each also looked up or created a GHL contact (many
  "create contact 429" while GHL throttled us), so Tampa's GHL now holds a large number of junk contacts tagged
  owner-account + consumer, source "Goes Local login".
- Other sites over the same 3 days: Orlando 99, Miami 89, NC 14, PA 4 emails — normal.
- Why it got through: /api/signup only limited repeats of the same email (5/hour). Nothing per visitor, nothing site-wide,
  no bot check. This is old code, not from v16.78–v16.80.

## Changes (worker)
- Any form submission (POST) from Tor is refused (403), except webhooks and /admin.
- /api/signup: hidden "website" field only bots fill in (filled → nothing sent); max 5 sign-ups per visitor (IP) per
  hour; at most 40 sign-up code emails per hour for the whole site (`AUTH.SIGNUP_EMAILS_PER_HOUR`); past it nothing is
  sent, visitors see "very busy, try again in an hour", and the dev team gets one alert per hour.

## Cloudflare (scripts/security-rules.mjs)
- New WAF rule "GL: block form submissions from Tor" on all 9 zones, so Tor POSTs never reach the site at all.

## Tests
- 80/80 local (new T39: bot-filled hidden field sends nothing).

## Status
- Live on Orlando, Miami, Tampa (28 Oct). Live check on Tampa: sign-up page 200 with the hidden field; a sign-up with
  the hidden field filled goes to the home page and sends nothing.
- WAF rule "GL: block form submissions from Tor" applied to all 9 zones (3 cities + 6 states) the same day.
- The 6 state sites still run the older worker (states chat deploys them); the Tor WAF rule protects them meanwhile.
